A browser console for running and automating an Adventure Land party. Connect characters playing through Steam or run them headless, then manage the party from one dashboard.

## What It Does

- **Party dashboard** — see character status and manage farming settings, equipment, and merchant controls.
- **Steam or headless play** — connect your game client or run offline characters without keeping the game window open.
- **Guided setup** — connect your account, choose your characters, and configure your game client from the browser.
- **Editable automation** — customize the character logic and dashboard, with hot reload available during development.
- **Windows and Docker releases** — install a Windows package or deploy with Docker Compose, with optional managed updates from the dashboard.
- **Market integration** — browse public ALData market listings and optionally set up authentication to publish classifieds.

## Get Started

Find the source, setup instructions, and release downloads on [GitHub](https://github.com/Ryan-Haines/adventureland-party-console). Native Linux setups are supported too, including Raspberry Pi with a 64-bit OS.
